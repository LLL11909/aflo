Design Features

设计亮点。

01

3D 模型展示

model-viewer + Three.js 驱动，5 款车型统一尺寸居中，自由缩放旋转。

02

图片序列滚动

106 帧图片替代视频，纯 JS 驱动，0 依赖，流畅度优于 video.currentTime。

03

Museum Gallery

2×2 大图网格 + 毛玻璃展开弹窗 + 模糊渐清文字动画。

04

Network Dashboard

数据卡片 + 活动流，Stripe/Uber 风格，非抽象网络图。

05

磁吸悬停

Gallery 卡片和按钮跟随鼠标产生 3D 透视微旋转。

06

粒子交互 Logo

Canvas 粒子系统，文字由粒子聚合，鼠标划过散开。灵感来自 Opal Electronics。

07

双语言切换

中英文两版独立部署，导航栏一键切换，localStorage 记忆偏好。

08

响应式适配

桌面 / 平板 / 手机全适配，移动端汉堡菜单，触摸目标 ≥ 44px。
