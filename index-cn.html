Key Features

不是每一个参数都值得拿出来说。
但这五个，值得。Five features worth talking about.

Modular

一个底盘，五种上装。5 分钟切换，无需工具——我们在谈真正的模块化，不是「假装模块化」。

Rugged

IP68 防护等级。从撒哈拉的沙尘到雨季的泥泞。不是在实验室测的——在非洲最极端的环境下实测。

Affordable

运营成本比传统燃油车低 60%。不是靠补贴——是靠电驱动、模块化维修、自动驾驶节省的人力成本。

Maintainable

坏了哪个换哪个。不需要送回原厂——当地技师就能修。在非洲，这不是加分项，是必选项。

Sustainable

纯电驱动，太阳能充电兼容。8 年无限公里三电质保。我们不是在卖车——是在投资非洲的未来。
